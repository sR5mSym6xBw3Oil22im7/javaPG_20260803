# わたしのTodo

素のJava（標準機能だけで動くJava）で作った、シンプルなTodoアプリです。

## できること

- Todoを追加する
- Todoの一覧を見る
- Todoを完了状態にする
- 完了状態を取り消す
- Todoを削除する

「完了」をクリックすると、Todoの状態が切り替わります。

- ✔がないTodoをクリックすると、✔が付きます
- ✔があるTodoをクリックすると、✔が消えます

## 必要なもの

- Javaが使える環境
- Webブラウザ

## 起動方法

コマンドプロンプト（文字で操作する画面）やターミナル（コマンドを入力する画面）で、`App.java` があるフォルダーを開きます。

### 1. コンパイルする

コンパイル（Javaのコードを実行できる形に変換すること）を行います。

```text
javac App.java
```

### 2. アプリを起動する

```text
java App
```

### 3. ブラウザで開く

Webブラウザのアドレス欄に、次のアドレスを入力します。

```text
http://localhost:8080
```

## 使い方

1. 入力欄にやることを入力します。
2. 「追加」をクリックします。
3. 終わったTodoの「完了」をクリックします。
4. もう一度「完了」をクリックすると、✔が消えて未完了に戻ります。
5. 不要なTodoは「削除」をクリックします。

## アプリの停止方法

アプリを起動した画面で、`Ctrl` キーを押しながら `C` キーを押します。

## ファイル

- `App.java`：HTTPサーバー（ブラウザからの通信を受け付ける仕組み）を使ったTodoアプリ本体
- `Hello.java`：挨拶を表示するJavaの練習用サンプル
- `Item.java`：1件のTodoをHTMLのリスト項目として表示する練習用サンプル
- `Items.java`：複数のTodoを配列（複数の値をまとめる仕組み）で扱う練習用サンプル
- `Main.java`：`ArrayList`（複数のTodoを入れる箱）を使って一覧を表示する練習用サンプル
- `README.md`：この説明書
- `.gitignore`：Git（ファイルの変更履歴を管理する仕組み）で管理しないファイルを指定する設定
- `AGENTS.md`：このプロジェクトで作業するときのルール

### コンパイル後に作られるファイル

`.class` ファイルは、`javac` コマンドでコンパイル（Javaのコードを実行できる形に変換）したときに作られるファイルです。通常は直接編集しません。

- `App.class`：`App.java` から作られた実行用ファイル
- `Hello.class`：`Hello.java` から作られた実行用ファイル
- `Item.class`：`Item.java` から作られた実行用ファイル
- `Items.class`：`Items.java` から作られた実行用ファイル
- `Main.class`：`Main.java` から作られた実行用ファイル
- `Todo.class`：`App.java` または `Main.java` にあるTodoクラスから作られた実行用ファイル

## 動作確認

「完了」を1回クリックすると✔が消え、もう1回クリックすると✔が再表示されることを、ブラウザ画面で確認します。
